# ProductMind Skills — Viability Assessment

**Date**: 2026-04-13

## Scores

| Dimension | Score | Rationale |
|---|---|---|
| Problem Clarity & Urgency | **Strong** | Builders using AI coding tools lack curated, product-aware skills. Most skills repos are pure engineering — no product thinking baked in. The skills ecosystem is booming (25,000+ skills on SkillsMP, 232+ in the largest GitHub repos) but product-engineering fusion is absent. |
| Target User Definition | **Strong** | Multi-skilled builders: engineers who also think about product, using Claude Code (and compatible agents). They want to ship important software, not just write code. Specific, identifiable, growing audience. |
| Competitive Landscape | **Moderate** | The Claude Code skills space is active — alirezarezvani/claude-skills (232+ skills, 5,200+ stars), daymade/claude-code-skills (48 production-ready skills), Anthropic's official skills repo, SkillsMP marketplace (25,000+ skills). However, none focus on product-engineering integration. The gap is real. Risk: space is moving fast and Anthropic controls the platform. |
| Differentiation | **Strong** | ProductMind's angle is structural: product thinking as a first-class concern in every skill, not an afterthought. No competitor occupies this niche. The brand "ProductMind" reinforces the positioning. |
| Technical Feasibility | **Strong** | Skills are Markdown files following the open SKILL.md standard. No unknown technology. The builder already has working skills in this repo. |
| Revenue / Impact Path | **Moderate** | Primary impact: reputation and brand building for ProductMind. Open source creates trust, visibility, and community. Revenue is indirect — consulting, speaking, community leadership. Clear impact path, less clear monetization. |

## Decision

**0 Weak scores — Proceed with confidence.**

The project sits in a validated, growing market with a genuine differentiation angle that no current competitor occupies.

## Risks to Monitor

1. **Platform risk**: Anthropic could change the skills format or launch a curated marketplace that shifts distribution dynamics.
2. **Commoditization**: As more skills repos appear, quality and curation become the differentiator — maintain high standards.
3. **Maintenance burden**: Skills need updating as Claude Code evolves. Plan for ongoing curation, not just initial creation.
