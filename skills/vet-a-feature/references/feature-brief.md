# Feature Brief — template

Generated only when the verdict is **BUILD** or **BUILD_SMALLER**. Keep it to one page.

```markdown
# [Feature name] — Feature Brief

## Problem
The sharp problem this feature solves, and for whom (the target customer).
One paragraph. Cite the sharpness verdict + the ≥3x rationale.

## Smallest version (ship this first)
SLC or MVP? The halved required-steps list. The smallest activating loop.
What we are deliberately NOT building in v1.

## Success metric
One leading-indicator value metric (a simple whole number, not revenue).
Pre-PMF note: if this is a new incubation, it is NOT held to the mature North Star yet.

## Strategy fit
The line of sight from this feature to the product's mission / North Star.

## What this is NOT
Scope boundaries — the adjacent things people will ask for that we are saying no to.

## Open questions / what would raise confidence
The missing inputs from the vet, and what evidence to gather.
```
