# Prototypes

This directory holds HTML/CSS prototypes for any UI-facing work in ProductMind Skills.

## Workflow

1. **Prototype first** — sketch the interaction in plain HTML/CSS before building in a framework
2. **Iterate with feedback** — share the prototype, gather input, refine
3. **Then build** — move to production code only after the prototype is validated

## When to Use

- GitHub Pages landing page for the skills collection
- Skill browser / catalog UI (if we build one)
- Interactive documentation or skill previews
