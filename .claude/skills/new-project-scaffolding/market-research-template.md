# Market Research Template

## Structure

### 1. Market Overview (2-3 paragraphs)

- What space is this in?
- How big is it? (TAM/SAM/SOM if relevant, otherwise qualitative sizing)
- What trends are shaping it right now?

### 2. Direct Competitors (3-5 minimum)

For each:

| Field | Detail |
|---|---|
| Name | |
| What they do | One sentence |
| Pricing model | Free/freemium/paid/enterprise |
| Strengths | What they do well |
| Weaknesses | Where they fall short |
| User sentiment | Summary from reviews, forums, social |

### 3. Adjacent Products

Products that partially solve the same problem or serve the same user for a different job. These often reveal positioning opportunities.

### 4. Differentiation Map

A 2x2 or simple table showing where competitors cluster and where the whitespace is.

### 5. Pricing & Business Model Patterns

What models work in this space? What do users expect to pay? What's the dominant pattern (SaaS, usage-based, one-time, ad-supported)?

### 6. User Signals

- App store reviews (common complaints, feature requests)
- Reddit/forum threads (what people wish existed)
- Twitter/social mentions (emerging frustrations)

### Research Depth Levels

- **Quick scan** (30 min equivalent): Competitors + pricing + one signal source. Use for side projects.
- **Standard** (2 hr equivalent): Full template above. Use for anything you'll ship.
- **Deep** (half-day equivalent): Standard + user interviews summary + TAM/SAM sizing + regulatory scan. Use for funded projects.

Default to **Standard** unless the user specifies otherwise.
